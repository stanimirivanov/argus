# Domain docs

## Before exploring

- Read the root `GLOSSARY.md` when present. This repository has one domain context for change intelligence, test selection and adaptation.
- Read relevant ADRs through the [decision index](../adr/README.md). Surface conflicts with accepted decisions and follow the index for supersession.
- At a cross-product boundary, use the producer's published evidence contract and the terms it defines. Consult the [Perfeng glossary](https://github.com/stanimirivanov/perfeng-contracts/blob/main/GLOSSARY.md) for Perfeng-owned vocabulary.

## Record terms and decisions

Record agreed local terms in this repository's root `GLOSSARY.md`. Extend the existing
ADR sequence and index in `docs/adr/`. Record decisions with the component that
owns the behavior and link related decisions across repositories.
