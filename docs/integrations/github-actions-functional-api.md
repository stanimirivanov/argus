# GitHub Actions functional API shadow execution

## TL;DR

- Generate a deterministic execution plan from one execution manifest and a
  reviewed repository-binding file.
- Feed the plan's flat `jobs` array directly to a GitHub Actions matrix.
- Check out every test repository at the immutable revision in its planned job.
- Map adapter IDs to literal, reviewed commands; never execute a command from
  a manifest, binding, plan, or matrix value.
- Give execution jobs no database secret. Upload normalized attempts and ingest
  them later in a trusted job.
- Always run every planned `full-suite` job. It remains authoritative while
  selection is in shadow mode.
- Bind every planned group to its explicit attempt IDs and publish one
  complete-plan recall report, including full-only groups.

This guide is a reference handoff, not a repository-specific turnkey workflow.
Copy it into the repository that owns the CI trigger, replace the explicit
adapter-command mapping, and bind the named secrets and immutable Argus ref.

## Inputs and trust boundaries

The workflow consumes three reviewed or generated inputs:

1. `execution-manifest.json` is generated by Argus selection and contains the
   test decisions, but no checkout revision or executable command.
2. `.argus/functional-api-execution-bindings.json` is reviewed CI
   configuration. It binds every repository/adapter group in the manifest to a
   stable group key and immutable test revision.
3. The workflow maps each supported adapter ID to one literal repository-owned
   command.

The binding file has this shape:

~~~json
{
  "apiVersion": "argus.dev/functional-api-execution-bindings/v1",
  "groups": [
    {
      "groupKey": "orders-playwright",
      "testRepository": {
        "provider": "github",
        "host": "github.com",
        "providerRepositoryId": "R_orders_tests_01",
        "owner": "example",
        "name": "orders-tests"
      },
      "testRevision": {
        "algorithm": "git-sha1",
        "digest": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
      },
      "adapter": "playwright"
    }
  ]
}
~~~

The planner rejects a missing, extra, duplicate, or coordinate-mismatched
binding. A binding intentionally does not contain a command, token, runner
label, environment, or per-change manifest digest. The generated plan contains
the canonical manifest digest and is the immutable handoff to execution.

## Select functional API tests

After the approved base-revision catalog and matching change impact have been
stored, generate the functional API v1 execution manifest:

~~~sh
go run ./cmd/select \
  -provider github \
  -delivery-id 01234567-89ab-cdef-0123-456789abcdef \
  > ./execution-manifest.json
~~~

With complete mapped impact, tests sharing an affected capability are
`RUN_REQUIRED`; other functional API candidates are `SKIP_FOR_NOW` in the
early stage and required in the later full-suite control. Partial, empty, or
unmapped impact requires every functional API candidate. The manifest also
reports affected capabilities with no mapped test. The browser selection
manifests are different versions and are **not** accepted by this planner or
runner; see [functional UI selection](functional-ui-selection.md).

## Generate the matrix

Create the plan before any test repository is executed:

~~~sh
go run ./cmd/plan-functional-api \
  -manifest ./execution-manifest.json \
  -bindings ./.argus/functional-api-execution-bindings.json \
  > ./execution-plan.json

jq -c '.jobs' ./execution-plan.json
~~~

Jobs are ordered by group key, with `selected` before `full-suite`. A selected
job exists only when the group contains at least one `RUN_REQUIRED` test. Every
non-empty group has a full-suite job, including a group for which selection
chose no early tests. The portable contract permits larger plans, but the
reference workflow fails before expansion when the plan exceeds GitHub
Actions' [256-job matrix limit](https://docs.github.com/en/actions/reference/limits#existing-system-limits).

## Reference reusable workflow

The following workflow assumes an earlier trusted job uploaded
`execution-manifest.json` as the artifact named by `manifest_artifact`. Pin
`argus_ref` to a reviewed immutable commit or release revision. The action
references use major release tags in accordance with this repository's policy.

~~~yaml
name: Argus functional API shadow

on:
  workflow_call:
    inputs:
      argus_ref:
        description: Reviewed immutable Argus revision
        required: true
        type: string
      manifest_artifact:
        description: Artifact containing execution-manifest.json
        required: true
        type: string
    secrets:
      TEST_REPOSITORY_TOKEN:
        description: Read-only token for private test repositories
        required: true
      ARGUS_DATABASE_URL:
        description: Runtime database URL used only by trusted ingestion
        required: true

permissions:
  contents: read

jobs:
  plan:
    runs-on: ubuntu-latest
    outputs:
      jobs: ${{ steps.matrix.outputs.jobs }}
    steps:
      - name: Check out CI configuration
        uses: actions/checkout@v7

      - name: Check out Argus
        uses: actions/checkout@v7
        with:
          repository: stanimirivanov/argus
          ref: ${{ inputs.argus_ref }}
          path: argus
          persist-credentials: false

      - name: Set up Go
        uses: actions/setup-go@v7
        with:
          go-version-file: argus/go.mod

      - name: Download execution manifest
        uses: actions/download-artifact@v8
        with:
          name: ${{ inputs.manifest_artifact }}
          path: input

      - name: Generate execution plan
        working-directory: argus
        run: >-
          go run ./cmd/plan-functional-api
          -manifest ../input/execution-manifest.json
          -bindings ../.argus/functional-api-execution-bindings.json
          > ../input/execution-plan.json

      - id: matrix
        name: Publish matrix
        shell: bash
        run: |
          set -euo pipefail
          count="$(jq '.jobs | length' input/execution-plan.json)"
          if (( count > 256 )); then
            echo "Execution plan has $count jobs; partition it before using a GitHub matrix." >&2
            exit 1
          fi
          echo "jobs=$(jq -c '.jobs' input/execution-plan.json)" >> "$GITHUB_OUTPUT"

      - name: Preserve planning evidence
        uses: actions/upload-artifact@v7
        with:
          name: argus-execution-plan-${{ github.run_id }}-${{ github.run_attempt }}
          path: |
            input/execution-manifest.json
            input/execution-plan.json
          if-no-files-found: error

  execute:
    needs: plan
    if: needs.plan.outputs.jobs != '[]'
    strategy:
      fail-fast: false
      matrix:
        job: ${{ fromJSON(needs.plan.outputs.jobs) }}
    runs-on: ubuntu-latest
    steps:
      - name: Check out Argus
        uses: actions/checkout@v7
        with:
          repository: stanimirivanov/argus
          ref: ${{ inputs.argus_ref }}
          path: argus
          persist-credentials: false

      - name: Check out immutable test revision
        uses: actions/checkout@v7
        with:
          repository: ${{ matrix.job.testRepository.owner }}/${{ matrix.job.testRepository.name }}
          ref: ${{ matrix.job.testRevision.digest }}
          path: test-repository
          token: ${{ secrets.TEST_REPOSITORY_TOKEN }}
          persist-credentials: false

      - name: Set up Go
        uses: actions/setup-go@v7
        with:
          go-version-file: argus/go.mod

      - name: Download planning evidence
        uses: actions/download-artifact@v8
        with:
          name: argus-execution-plan-${{ github.run_id }}-${{ github.run_attempt }}
          path: input

      - name: Build trusted runner
        working-directory: argus
        run: |
          mkdir -p ../bin
          go build -o ../bin/run-functional-api ./cmd/run-functional-api

      - id: execute
        name: Execute planned group
        continue-on-error: true
        shell: bash
        working-directory: test-repository
        env:
          ATTEMPT_ID: ${{ github.run_id }}-${{ github.run_attempt }}-${{ matrix.job.groupKey }}-${{ matrix.job.stage }}
          ADAPTER: ${{ matrix.job.adapter }}
          STAGE: ${{ matrix.job.stage }}
          TEST_PROVIDER: ${{ matrix.job.testRepository.provider }}
          TEST_HOST: ${{ matrix.job.testRepository.host }}
          TEST_REPOSITORY_ID: ${{ matrix.job.testRepository.providerRepositoryId }}
          TEST_REVISION_ALGORITHM: ${{ matrix.job.testRevision.algorithm }}
          TEST_REVISION: ${{ matrix.job.testRevision.digest }}
        run: |
          set -euo pipefail
          attempt="../attempt-${{ matrix.job.groupKey }}-${{ matrix.job.stage }}.json"
          common=(
            -manifest ../input/execution-manifest.json
            -stage "$STAGE"
            -attempt-id "$ATTEMPT_ID"
            -test-provider "$TEST_PROVIDER"
            -test-host "$TEST_HOST"
            -test-repository-id "$TEST_REPOSITORY_ID"
            -test-revision-algorithm "$TEST_REVISION_ALGORITHM"
            -test-revision "$TEST_REVISION"
            -adapter "$ADAPTER"
          )

          case "$ADAPTER" in
            playwright)
              ../bin/run-functional-api "${common[@]}" -- \
                node ./tools/argus-playwright-adapter.mjs > "$attempt"
              ;;
            pytest)
              ../bin/run-functional-api "${common[@]}" -- \
                python ./tools/argus_pytest_adapter.py > "$attempt"
              ;;
            *)
              echo "Unsupported reviewed adapter: $ADAPTER" >&2
              exit 2
              ;;
          esac

      - name: Upload normalized attempt
        if: always()
        uses: actions/upload-artifact@v7
        with:
          name: argus-attempt-${{ github.run_id }}-${{ github.run_attempt }}-${{ matrix.job.groupKey }}-${{ matrix.job.stage }}
          path: attempt-${{ matrix.job.groupKey }}-${{ matrix.job.stage }}.json
          if-no-files-found: error

      - name: Preserve execution failure
        if: steps.execute.outcome == 'failure'
        run: exit 1

  ingest:
    needs: [plan, execute]
    if: >-
      always() && needs.plan.result == 'success' &&
      needs.plan.outputs.jobs != '[]'
    runs-on: ubuntu-latest
    steps:
      - name: Check out Argus
        uses: actions/checkout@v7
        with:
          repository: stanimirivanov/argus
          ref: ${{ inputs.argus_ref }}
          persist-credentials: false

      - name: Set up Go
        uses: actions/setup-go@v7
        with:
          go-version-file: go.mod

      - name: Download normalized attempts
        uses: actions/download-artifact@v8
        with:
          pattern: argus-attempt-${{ github.run_id }}-${{ github.run_attempt }}-*
          path: attempts
          merge-multiple: true

      - name: Download execution plan
        uses: actions/download-artifact@v8
        with:
          name: argus-execution-plan-${{ github.run_id }}-${{ github.run_attempt }}
          path: input

      - name: Ingest immutable evidence and evaluate the complete plan
        shell: bash
        env:
          ARGUS_DATABASE_URL: ${{ secrets.ARGUS_DATABASE_URL }}
        run: |
          set -euo pipefail
          expected="$(jq '.jobs | length' input/execution-plan.json)"
          actual="$(find attempts -type f -name '*.json' | wc -l)"
          if (( actual != expected )); then
            echo "Expected $expected attempt documents, downloaded $actual." >&2
            exit 1
          fi

          while IFS= read -r -d '' attempt; do
            go run ./cmd/execution-evidence ingest -file "$attempt"
          done < <(find attempts -type f -name '*.json' -print0)

          prefix="${{ github.run_id }}-${{ github.run_attempt }}"
          jq --arg prefix "$prefix" '
            {
              apiVersion: "argus.dev/execution-plan-attempt-bindings/v1",
              groups: [
                .jobs | group_by(.groupKey)[] |
                . as $jobs | $jobs[0].groupKey as $group |
                {
                  groupKey: $group,
                  selectedAttemptId: (
                    if any($jobs[]; .stage == "selected")
                    then ($prefix + "-" + $group + "-selected")
                    else null
                    end
                  ),
                  fullSuiteAttemptId: ($prefix + "-" + $group + "-full-suite")
                }
              ]
            }
          ' input/execution-plan.json > input/attempt-bindings.json

          mkdir -p reports
          go run ./cmd/execution-evidence plan-shadow-report \
            -plan input/execution-plan.json \
            -attempt-bindings input/attempt-bindings.json \
            > reports/plan.json

      - name: Upload shadow reports
        if: always()
        uses: actions/upload-artifact@v7
        with:
          name: argus-plan-shadow-report-${{ github.run_id }}-${{ github.run_attempt }}
          path: reports
          if-no-files-found: ignore
~~~

## Failure and authority semantics

The execution step uses `continue-on-error` only long enough to upload a valid
attempt document. The following step restores the failure to the matrix job.
The ingestion job uses `always()` so normalized evidence remains durable even
when a selected or full-suite test failed. Malformed output produces no valid
attempt and therefore fails artifact upload rather than inventing evidence.

The full-suite job is the release authority during shadow mode. A selected
failure may fail fast according to repository policy, but a selected success
does not replace the control. Keep `fail-fast: false` so one group cannot
cancel the controls for other groups.

The plan-level report validates every attempt against its planned manifest,
repository, revision, adapter, stage, and test count. A group with no selected
job remains in the recall denominator: every failure in its full-suite attempt
is a `not-selected` miss. The older pairwise report remains available for
focused diagnosis, but it is not the complete-plan safety metric.

## Security and repository-specific work

- Restrict the cross-repository checkout token to read-only access to the
  required test repositories and disable credential persistence.
- Do not expose the database URL, artifact-store credentials, release tokens,
  or deployment credentials to test code. Only the trusted ingestion job needs
  the database URL.
- Protect the binding file and adapter-command mapping with repository review
  and ownership rules.
- Resolve `argus_ref` to reviewed immutable content. Do not use a moving branch
  for evidence-producing runs.
- Add dependency installation and caches inside each literal adapter branch.
  Treat lockfiles from the checked-out test revision as untrusted input.
- Give forked or otherwise untrusted pull requests a separate policy. GitHub
  does not supply ordinary secrets to fork workflows, and bypassing that
  boundary would expose cross-repository credentials.
- Upload referenced evidence bytes before ingestion when adapter results name
  artifacts. Attempt ingestion registers metadata and checksums; it does not
  copy or verify remote object bytes.

## Local rehearsal

Before enabling a repository, exercise its real manifest and binding file
without credentials:

~~~sh
go run ./cmd/plan-functional-api \
  -manifest ./execution-manifest.json \
  -bindings ./.argus/functional-api-execution-bindings.json \
  > ./execution-plan.json

jq -e '
  .apiVersion == "argus.dev/functional-api-execution-plan/v1" and
  ([.jobs[] | select(.stage == "full-suite")] | length > 0)
' ./execution-plan.json
~~~

Then run one selected and one full-suite job through
[`run-functional-api`](functional-api-adapters.md), verify both normalized
attempts, and test an explicit
[`plan-shadow-report`](functional-api-adapters.md#reference-ci-invocation)
before granting the ingestion job database access.
